Sum Rule / 합의 법칙

English original theorem
If a task can be done in m ways and another mutually exclusive task can be done in n ways, then one of the tasks can be done in m+n ways.
한글 번역
서로 동시에 일어나지 않는 두 선택이 각각 m가지, n가지라면 둘 중 하나를 고르는 방법은 m+n가지이다.
실생활 예시 1: 동아리 선택
학생이 과학 동아리 4개 또는 예술 동아리 3개 중 하나만 가입한다면 총 선택지는 4+3=7개이다. 두 종류를 동시에 선택하지 않으므로 합의 법칙을 쓴다.
풀이 핵심: 문제에서 구해야 하는 대상을 정리의 조건과 대응시킨 뒤, 공식이나 판정 조건을 적용한다. 계산 결과는 실제 선택 수, 연결 가능성, 최단 경로, 배정 가능성처럼 해석한다.
실생활 예시 2: 할인 쿠폰 경로
음수 비용 간선이 있어도 음수 사이클이 없으면 벨만-포드로 최저 비용 경로를 찾을 수 있다.

English original theorem
